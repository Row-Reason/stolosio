Stolosio is an open-source, self-hosted browser and web-acquisition gateway. It gives your CDP-compatible automation one endpoint for a managed Browserless fleet and optional paid Browserless cloud capacity, plus a capture endpoint that returns a page's content using the cheapest method that works.

**Keep your automation. Use only the browser you need.**

```text
ws://localhost:8411/v1/connect
```

## How it works

Your client connects to Stolosio, which acquires a browser from the provider the session names, the managed Browserless fleet by default. Native CDP traffic then passes through to it. Clients that only need a page's content call `POST /v1/capture`, which fetches plain HTTP when that is enough and renders in a browser otherwise.

Stolosio owns admission, queues, session lifecycle, fleet capacity, and cost accounting. PostgreSQL is the durable source of truth. A separate fleet controller manages browser workers on Docker or Kubernetes.

## Current status

Stolosio is **experimental**, intended for local development and trusted networks. There are no supported production releases, multi-tenant guarantees, or API/database compatibility guarantees yet.

The CDP, DEBUG, admin, and metrics endpoints have no application-level access control. An installation's externally protected admin interface does not add built-in authentication to Stolosio. Read the [security guide](/docs/security/) before deployment.
