# pagecapture

A page's content as a person would receive it, at the lowest cost that achieves it: plain HTTP when that is
enough, an adaptive browser render when it isn't, challenge resolution only when asked for — and when none of that
gives trustworthy content, a clear failure that says why (bot challenge, login wall, 404, rate limit, …).

Built for a generic public crawler that meets new domains all the time: no per-site configuration. Designed to run
as stolosio's `POST /v1/capture` endpoint, with periplus as a downstream client. The contract is `docs/api.md`.

```python
from pagecapture import CaptureRequest, CaptureService

service = CaptureService()
result = await service.capture(CaptureRequest(url="https://jp.mercari.com/en/search?category_id=97"))
result.outcome              # "captured" | "failed"
result.document             # representation ("response_body" | "rendered_html"), media type, body, sha256
result.failure              # code, category (website | network | gateway | content), transient, retry_after_seconds
result.evidence.attempts    # every step taken: path, tier, assessment, decision
result.to_json()            # the endpoint's response body
```

```bash
uv run pagecapture capture "https://jp.mercari.com/en/search?category_id=97"   # --json for the response body
uv run pagecapture classify https://example.com/                                # plain-HTTP assessment only
```

## How it works

```
plain HTTP ─► classify ─► blocked / broken / unreachable ─────────────────────────────► failed, with evidence
                 ├─ looks usable + method cache says HTTP is enough here ─────────────────► captured (response_body)
                 ├─ otherwise: managed browser (adaptive render) ─► compare with plain HTTP ─► captured (verified
                 │                                                     HTTP bytes, or the rendered DOM) + remember
                 └─ bot challenge ─► challenge resolution, if requested ──────────────────► captured
```

- **Classify** (`classify/`): rules where they are exact and generalise (status codes, payload types, bot-protection
  fingerprints, redirects, explicit wording). Stops early when rules are certain. Whether a browser adds content
  is measured, not predicted: pages are rendered and compared.
- **Render** (`render/`): one generic algorithm that decides per page, while rendering, how long to wait and whether
  to scroll; collects content across snapshots; blocks images and fonts.
- **Service** (`service.py`): render by default, the escalation ladder, trust decisions and evidence; `failures.py`
  maps assessments to the contract's failure codes.
- **Method cache** (`cache.py`): remembers, per URL and URL pattern, where rendering confirmed plain HTTP was
  enough, so later captures skip the browser (30-day TTL, canary re-checks, invalidated on contradiction).
- **Adapters** (`adapters.py`): the host plugs in its HTTP fetcher and browser tiers; defaults use httpx and
  CDP endpoints.

Details: `docs/architecture.md`.

## Configuration

Environment variables (all settings: `src/pagecapture/config.py`); keep them in a `.env` and run with
`uv run --env-file .env …`:

```
PAGECAPTURE_BROWSER_WS=ws://…            # managed browser tier (CDP, browserless-compatible)
PAGECAPTURE_CHALLENGE_BROWSER_WS=https://production-sfo.browserless.io/stealth/bql?token=…&proxy=residential
                                         # optional: challenge-resolution tier (BrowserQL, or any ws:// CDP endpoint)
PAGECAPTURE_CHALLENGE_PROXIED=1          # optional: that tier egresses through proxies, so block pages get a try
PAGECAPTURE_PROXY_COUNTRY=jp             # residential exit country for the BrowserQL tier (default jp)
PAGECAPTURE_METHOD_CACHE=cache.sqlite    # optional: persist the method cache (default: in memory)
```

## Status

Proof of concept with benchmarks (`docs/benchmarks.md`): rules are near-exact on blocked and broken pages. On the
random web, rendering adds real content to ~29% of pages and a raw-HTML classifier finds fewer than half of them,
so the service renders by default and learns, per URL and URL pattern, where plain HTTP is enough. The adaptive
renderer gets 99% of the content lines at a median 6.5 s; end to end, outcomes agree with audited labels on 96–97%
of pages. Part of stolosio as a uv workspace package; stolosio serves it as `POST /v1/capture`.
